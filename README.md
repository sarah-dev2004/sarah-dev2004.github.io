# Sarah's Portfolio Website

A personal portfolio website that showcases my skills, projects and contact details.

🔗 **Live site:** [https://sarah-dev2004.github.io/](https://sarah-dev2004.github.io/)

## About

I built this portfolio to present my work and introduce myself to recruiters and employers. It is lightweight, fast and hosted for free with HTTPS on GitHub Pages.

## Built With

- **HTML5**: page structure
- **CSS3**: styling and layout
- **JavaScript**: interactivity
- **GitHub Pages**: hosting with HTTPS

## Features

- Clean, simple design
- Sections for about me, skills, projects and contact
- Works on desktop and mobile
- Deployed live with a secure HTTPS link


## Run Locally

1. Download or clone this repository
2. Open `index.html` in your browser
